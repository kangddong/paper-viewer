Attention Is All You Need

어텐션만 있으면 충분하다

Ashish Vaswani · Noam Shazeer · Niki Parmar · Jakob Uszkoreit · Llion Jones · Aidan N. Gomez · Łukasz Kaiser · Illia Polosukhin

📋 핵심 요약 (Executive Summary)

기존의 뛰어난 시퀀스 변환(Sequence Transduction) 모델들은 인코더와 디코더를 포함하는 복잡한 순환 신경망(RNN) 또는 합성곱 신경망(CNN)을 기반으로 합니다. 본 논문에서는 순환과 합성곱을 완전히 배제하고 오로지 어텐션 메커니즘에만 기반한 새로운 신경망 구조인 트랜스포머(Transformer)를 제안합니다.

  • 병렬화 최적화: 순환 구조를 제거하여 학습 시 병렬화 가능 → 학습 시간 획기적 단축
  • SOTA 달성: WMT 2014 영독 28.4 BLEU, 영불 41.8 BLEU로 기존 모델 능가
  • 범용성: 기계 번역뿐만 아니라 영어 구문 분석(Parsing) 등 다양한 태스크에서 우수한 성능

1. 서론 (Introduction)

순환 신경망(Recurrent Neural Networks), 특히 LSTM(Long Short-Term Memory)과 GRU(Gated Recurrent) 신경망은 언어 모델링이나 기계 번역과 같은 시퀀스 모델링 및 변환 문제에서 최첨단(state-of-the-art) 접근 방식으로 확고히 자리 잡았습니다. 이후 수많은 노력들이 순환 언어 모델과 인코더-디코더 구조의 한계를 계속해서 넓혀 왔습니다.

순환 모델은 일반적으로 입력 및 출력 시퀀스의 심볼 위치에 따라 계산을 분할합니다. 계산 시간의 단계에 맞춰 위치를 정렬하고, 이전 은닉 상태 ht-1과 위치 t의 입력을 함수로 하여 일련의 은닉 상태 ht를 생성합니다. 이러한 본질적인 순차적 특성은 학습 예제 내의 병렬화를 방해하며, 이는 메모리 제약으로 인해 예제 간 배치 처리가 제한되는 긴 시퀀스 길이에서 치명적인 문제가 됩니다. 최근 연구는 계수화(Factorization) 트릭과 조건부 계산을 통해 계산 효율성을 상당히 개선했지만, 순차적 계산이라는 근본적인 제약은 여전히 남아 있습니다.

어텐션 메커니즘은 다양한 태스크에서 강력한 시퀀스 모델링 및 변환 모델의 필수적인 부분이 되었으며, 입력 또는 출력 시퀀스 내의 거리에 상관없이 의존성을 모델링할 수 있게 해줍니다. 그러나 몇몇 사례를 제외하면, 이러한 어텐션 메커니즘은 여전히 순환 신경망과 함께 사용되고 있습니다.

본 연구에서는 순환 구조를 피하고 대신 입력과 출력 사이의 전역적 의존성을 도출하기 위해 전적으로 어텐션 메커니즘에 의존하는 모델 구조인 트랜스포머(Transformer)를 제안합니다. 트랜스포머는 훨씬 더 많은 병렬화를 가능하게 하며, 8개의 P100 GPU에서 단 12시간 동안의 학습만으로도 번역 품질에서 새로운 최첨단 성능에 도달할 수 있습니다.

2. 배경 (Background)

순차적 계산을 줄이려는 목표는 Extended Neural GPU, ByteNet, 그리고 ConvS2S의 기초가 되기도 했습니다. 이 모델들은 모두 합성곱 신경망을 기본 블록으로 사용하여 모든 입력 및 출력 위치에 대해 은닉 표현을 병렬로 계산합니다. 이러한 모델들에서 두 임의의 입력 또는 출력 위치 사이의 신호를 연결하는 데 필요한 연산 수는 위치 사이의 거리에 따라 ConvS2S는 선형적으로, ByteNet은 로그 함수적으로 증가합니다. 이는 먼 거리의 위치 사이의 의존성을 학습하는 것을 더 어렵게 만듭니다. 트랜스포머에서는 이를 상수번의 연산으로 줄였습니다. 비록 어텐션 가중치가 적용된 위치들을 평균냄으로써 유효 해상도가 낮아지는 대가가 따르지만, 이는 3.2절에서 설명할 멀티 헤드 어텐션(Multi-Head Attention)으로 상쇄합니다.

때때로 인트라 어텐션(Intra-attention)이라고도 불리는 셀프 어텐션(Self-attention)은 시퀀스의 표현을 계산하기 위해 단일 시퀀스의 서로 다른 위치들을 연결하는 어텐션 메커니즘입니다. 셀프 어텐션은 독해, 요약문 생성, 텍스트 함의(Textual Entailment), 그리고 태스크 독립적인 문장 표현 학습 등 다양한 작업에서 성공적으로 사용되어 왔습니다.

엔드투엔드 메모리 네트워크는 시퀀스 정렬 순환 구조 대신 순환형 어텐션 메커니즘을 기반으로 하며, 간단한 언어의 질의응답 및 언어 모델링 태스크에서 좋은 성능을 보이는 것으로 입증되었습니다.

하지만 우리가 아는 한, 트랜스포머는 시퀀스 정렬 RNN이나 합성곱을 사용하지 않고 오직 셀프 어텐션에만 의존하여 입력과 출력의 표현을 계산하는 최초의 시퀀스 변환 모델입니다.

3. 모델 아키텍처 (Model Architecture)

대부분의 경쟁력 있는 신경망 시퀀스 변환 모델은 인코더-디코더 구조를 가집니다. 인코더는 입력 시퀀스의 심볼 표현 (x1, ..., xn)을 연속적인 표현 z = (z1, ..., zn)으로 매핑합니다. z가 주어지면 디코더는 한 번에 하나의 요소씩 출력 시퀀스 (y1, ..., ym)을 생성합니다. 각 단계에서 모델은 이전에 생성된 심볼들을 추가 입력으로 사용하는 자기회귀(Auto-regressive) 방식을 따릅니다.

3.1 인코더 및 디코더 스택 (Encoder and Decoder Stacks)

인코더 (Encoder)

인코더는 N=6개의 동일한 층이 쌓인 구조입니다. 각 층은 두 개의 서브 층을 가집니다. 첫 번째는 멀티 헤드 셀프 어텐션(Multi-head self-attention) 메커니즘이고, 두 번째는 단순한 위치별 완전 연결 피드포워드 네트워크(Position-wise fully connected feed-forward network)입니다. 우리는 각 서브 층마다 잔차 연결(Residual connection)을 도입하고, 그 뒤에 층 정규화(Layer normalization)를 수행합니다.

각 서브 층 출력 = LayerNorm(x + Sublayer(x))

모든 서브 층의 출력 차원: dmodel = 512

디코더 (Decoder)

디코더 또한 N=6개의 동일한 층이 쌓인 구조입니다. 인코더 층의 두 서브 층 외에도 디코더는 인코더 출력에 대해 멀티 헤드 어텐션을 수행하는 세 번째 서브 층을 갖습니다. 디코더 스택의 셀프 어텐션 서브 층은 이후 위치(미래 토큰)를 참조하지 못하도록 마스킹(Masking)을 적용합니다.

3.2 어텐션 (Attention)

그림 2: (a) 스케일드 닷-프로덕트 어텐션, (b) 멀티 헤드 어텐션 — 병렬로 동작하는 여러 어텐션 헤드로 구성됩니다.

3.2.1 스케일드 닷-프로덕트 어텐션 (Scaled Dot-Product Attention)

입력은 차원 dk의 쿼리(Query)와 키(Key), 그리고 차원 dv의 밸류(Value)로 구성됩니다. 모든 키에 대해 쿼리의 내적을 계산하고, 각각을 √dk로 나눈 뒤, 소프트맥스 함수를 적용하여 밸류에 대한 가중치를 얻습니다.

Attention(Q, K, V) = softmax( QKT / √dk ) V  —  (수식 1)

3.2.2 멀티 헤드 어텐션 (Multi-Head Attention)

단일 어텐션 함수를 쓰는 대신, 쿼리·키·밸류를 h번 서로 다른 선형 투영을 통해 투영하여 어텐션을 병렬로 수행합니다. 각 헤드의 dv 차원 출력을 이어붙인 후 다시 투영하여 최종 값을 얻습니다.

MultiHead(Q, K, V) = Concat(head1, ..., headh) WO

headi = Attention(QWiQ, KWiK, VWiV)

h = 8 헤드, dk = dv = dmodel/h = 64

3.2.3 어텐션의 활용 방식

  • 인코더-디코더 어텐션: 쿼리는 이전 디코더 층에서, 키·밸류는 인코더 출력에서 옵니다. 디코더의 모든 위치가 입력 시퀀스 전체에 주목할 수 있습니다.
  • 인코더 셀프 어텐션: 키·밸류·쿼리가 모두 인코더 이전 층 출력에서 옵니다.
  • 디코더 셀프 어텐션 (마스킹 적용): 미래 위치로의 정보 흐름을 막기 위해 -∞ 마스킹을 적용합니다.

3.3 포지션와이즈 피드포워드 네트워크

어텐션 서브 층 외에도, 각 층은 각 위치에 동일하게 적용되는 완전 연결 피드포워드 네트워크를 포함합니다.

FFN(x) = max(0, xW1 + b1) W2 + b2  —  (수식 2)

입출력 차원: dmodel = 512  |  내부 차원: dff = 2048

3.4 임베딩과 소프트맥스

입력·출력 토큰을 dmodel 차원의 벡터로 변환하는 학습된 임베딩을 사용합니다. 두 임베딩 층과 소프트맥스 이전 선형 변환 사이에 동일한 가중치 행렬을 공유합니다. 임베딩 층에서는 가중치에 √dmodel을 곱합니다.

3.5 위치 인코딩 (Positional Encoding)

순환 구조나 합성곱 없이 시퀀스 순서를 활용하기 위해, 입력 임베딩에 위치 인코딩을 더합니다. 사인·코사인 함수를 사용합니다:

PE(pos, 2i) = sin(pos / 100002i/dmodel)

PE(pos, 2i+1) = cos(pos / 100002i/dmodel)

4. 왜 셀프 어텐션인가 (Why Self-Attention)

셀프 어텐션 층을 순환 층 및 합성곱 층과 비교하여 세 가지 관점(계산 복잡도, 병렬화 가능성, 장거리 의존성 경로 길이)에서 우수성을 입증합니다.

표 1: 각 층 유형별 복잡도 비교

층 유형 층당 복잡도 순차 연산 최대 경로 길이
Self-Attention O(n² · d) O(1) O(1)
Recurrent (순환) O(n · d²) O(n) O(n)
Convolutional (합성곱) O(k · n · d²) O(1) O(logk(n))
Self-Attention (제한) O(r · n · d) O(1) O(n/r)

n: 시퀀스 길이, d: 표현 차원, k: 합성곱 커널 크기, r: 이웃 크기

셀프 어텐션 층은 상수 O(1)번의 순차 연산으로 모든 위치를 연결하는 반면, 순환 층은 O(n)이 필요합니다. 시퀀스 길이 n이 표현 차원 d보다 작을 때 셀프 어텐션이 순환 층보다 빠르며, 이는 기계 번역에서 거의 항상 참입니다.

5. 학습 (Training)

5.1 학습 데이터 및 배치

WMT 2014 영어-독일어 데이터셋(약 450만 문장 쌍), 영어-프랑스어(약 3,600만 문장)로 학습했습니다. 바이트-페어 인코딩(BPE)을 사용하여 37,000개(영독)·32,000개(영불) 공유 어휘를 구성했습니다.

5.2 하드웨어 및 스케줄

  • 기본(base) 모델: 8× NVIDIA P100 GPU, 100,000 스텝(약 12시간), 스텝당 0.4초
  • 빅(big) 모델: 동일 하드웨어, 300,000 스텝(3.5일), 스텝당 1.0초

5.3 옵티마이저

Adam 옵티마이저(β1=0.9, β2=0.98, ε=10-9)를 사용합니다. 학습률은 아래 수식으로 스케줄링됩니다:

lrate = dmodel−0.5 · min(step−0.5, step · warmup_steps−1.5)

warmup_steps = 4000 (이후 역제곱근 감소)

5.4 정규화

  • 잔차 드롭아웃: 각 서브 층 출력 및 임베딩+위치 인코딩 합산에 Pdrop=0.1 적용
  • 레이블 스무딩: εls=0.1 적용 → 당혹도(perplexity)는 다소 저하되나 정확도·BLEU 향상

7. 결론 (Conclusion)

본 연구에서는 순전히 어텐션에만 기반한 최초의 시퀀스 변환 모델인 트랜스포머(Transformer)를 제안했습니다. 인코더-디코더 구조에서 순환 층들을 멀티 헤드 셀프 어텐션으로 대체하여 다음을 달성했습니다:

  • WMT 2014 영독 번역 28.4 BLEU — 새로운 최첨단(이전 앙상블 대비 +2 BLEU 이상)
  • WMT 2014 영불 번역 41.8 BLEU — 이전 단일 모델 비용의 1/4 미만으로 달성
  • 영어 구문 분석(Constituency Parsing)에서도 우수한 일반화 성능 입증

어텐션 기반 모델을 이미지·오디오·비디오 등 다양한 모달리티로 확장하고, 지역적·제한적 어텐션으로 큰 입출력을 효율적으로 처리하는 것이 향후 연구 방향입니다.
