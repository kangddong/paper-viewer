# 📖 논문 번역 단어장 (Glossary)

본 프로젝트의 일관성 있는 번역을 위해 정의된 용어집입니다.

| 영문 용어 | 권장 번역어 | 비고 |
| :--- | :--- | :--- |
| **Co-design / Co-evolution** | 공동 설계 / 공진화 | 하드웨어와 소프트웨어가 함께 발전함 |
| **Memory Wall** | 메모리 벽 | 연산 속도에 비해 메모리 대역폭이 뒤처지는 현상 |
| **Intelligence per Joule** | 줄(Joule)당 지능 | 에너지 효율성을 강조하는 지표 |
| **Monolithic Integration** | 단일 통합 | 반도체 소자들을 하나의 칩 위에 적층하는 기술 |
| **Compute-in-Memory (CIM)** | 메모리 내 연산 | 데이터를 옮기지 않고 메모리 자체에서 연산 수행 |
| **Hardware-aware** | 하드웨어 인식형 | 하드웨어의 특성을 고려하여 모델을 최적화함 |
| **Heterogeneous Integration** | 이종 통합 | 서로 다른 공정의 칩들을 하나의 패키지로 묶음 |
| **Frontier Model** | 최첨단 모델 / 프론티어 모델 | GPT-4 등 가장 앞선 대규모 언어 모델들 |
| **Physics-informed AI** | 물리 법칙 기반 AI | 물리 법칙을 학습 과정에 제약 조건으로 포함 |
| **Sustainability** | 지속 가능성 | 환경적, 경제적 관점에서의 유지 가능함 |
| **Abstraction Layer** | 추상화 계층 | 복잡한 시스템을 단계별로 나눈 구조 |
| **Scale / Scaling** | 확장 / 스케일링 | 모델 크기나 연산량을 키우는 행위 |
| **Reliability** | 신뢰성 | 시스템의 안정적인 동작 여부 |
| **Action Items** | 행동 촉구 사항 / 실천 과제 | 향후 수행해야 할 구체적인 작업들 |
| **Interconnect** | 상호 연결 | 칩 내부 또는 칩 간의 데이터를 주고받는 통로 |
| **Throughput** | 처리량 | 단위 시간당 처리되는 데이터의 양 |
| **Packaging** | 패키징 | 완성된 반도체 칩을 보호하고 연결하는 공정 |
| **Latency** | 지연 시간 | 데이터 처리나 전송에 걸리는 시간 |
| **Reconfigurable** | 재구성 가능 | 필요에 따라 하드웨어 구조를 변경할 수 있는 |
| **EDA (Electronic Design Automation)** | 전자 설계 자동화 | 컴퓨터를 이용한 반도체 설계 자동화 도구 |
| **Power Delivery** | 전력 공급 | 칩에 안정적으로 전력을 전달하는 기술 |
| **Cooling** | 냉각 | 발생한 열을 배출하는 기술 |
| **System-level** | 시스템 수준 / 시스템 차원 | 개별 소자나 칩이 아닌 전체 시스템 관점 |
| **SDC (Silent Data Corruption)** | 침묵하는 데이터 오염 | 기록되거나 인식되지 않고 발생하는 데이터 오류 |
| **SMR (Small Modular Reactor)** | 소형 모듈형 원자로 | 차세대 전력 공급을 위한 차세대 원자력 기술 |
| **Dennard scaling** | 데나드 스케일링 | 트랜지스터 크기가 줄어들면 전력 밀도가 유지된다는 법칙 |
| **Physical AI** | 물리적 AI | 물리적 세계에서 행동하고 상호작용하는 AI (로봇 등) |
| **Embodied Agent** | 가상/실체형 에이전트 | 신체를 지니고 물리적 환경에서 작용하는 지능형 대리인 |
| **PPA (Power, Performance, Area)** | PPA (전력, 성능, 면적) | 반도체 설계의 3대 핵심 평가 지표 |
| **Attention** | 어텐션 | 문맥에서 중요한 부분에 집중하는 매커니즘 |
| **Self-Attention** | 셀프 어텐션 | 자기 자신의 요소들 사이의 관계를 계산하는 어텐션 |
| **Multi-Head Attention** | 멀티 헤드 어텐션 | 여러 개의 어텐션을 병렬로 수행하는 구조 |
| **Encoder / Decoder** | 인코더 / 디코더 | 정보를 부호화하고 복호화하는 핵심 구성 요소 |
| **Query, Key, Value** | 쿼리, 키, 밸류 | 어텐션 계산에 사용되는 세 가지 벡터 |
| **Recurrent** | 순환형 / 재귀형 | 시퀀스 데이터를 순차적으로 처리하는 방식 (RNN 등) |
| **Convolutional** | 합성곱 / 컨볼루션 | 국소적 특징을 추출하는 신경망 방식 (CNN 등) |
| **Sequence Transduction** | 시퀀스 변환 | 하나의 시퀀스를 다른 시퀀스로 바꾸는 작업 |
| **BLEU** | BLEU | 기계 번역 결과의 품질을 측정하는 지표 |
| **Parallelize / Parallelizable** | 병렬화 / 병렬화 가능 | 여러 연산을 동시에 처리할 수 있음 |
| **Positional Encoding** | 위치 인코딩 | 시퀀스 내 단어의 순서 정보를 제공하는 기법 |
| **Feed-forward** | 피드포워드 / 순전파 | 데이터가 한 방향으로만 흐르는 신경망 구조 |
| **State-of-the-Art (SOTA)** | 최첨단 / SOTA | 현재 가장 우수한 성능을 보이는 기술 수준 |
| **World Model (WM)** | 월드 모델 | 환경 동역학을 예측하는 모델 |
| **Joint Embedding Predictive Architecture (JEPA)** | 공동 임베딩 예측 아키텍처 / JEPA | 압축된 잠재 공간에서 미래 임베딩을 예측 |
| **Joint-Embedding** | 공동 임베딩 | 입력과 예측 대상을 같은 잠재 표현 공간에 사상 |
| **Latent Space / Latent Embedding** | 잠재 공간 / 잠재 임베딩 | 저차원 표현 공간 |
| **Predictor** | 예측기 | 다음 잠재 상태를 예측하는 모듈 |
| **Representation Collapse** | 표현 붕괴 | 서로 다른 입력이 거의 동일한 표현으로 수렴하는 현상 |
| **Stop-Gradient** | 기울기 차단 | 역전파를 일부 경로에서 막는 기법 |
| **Exponential Moving Average (EMA)** | 지수이동평균 | 타깃 네트워크 안정화 기법 |
| **Teacher Forcing** | 티처 포싱 | 정답 이전 상태를 다음 예측 입력으로 사용하는 학습 방식 |
| **Model Predictive Control (MPC)** | 모델 예측 제어 | 계획과 재계획을 반복하는 제어 전략 |
| **Cross-Entropy Method (CEM)** | 교차 엔트로피 방법 | 샘플 기반 최적화 기법 |
| **SIGReg** | SIGReg | 등방성 가우시안 잠재 분포를 유도하는 정규화기 |
| **Epps-Pulley Test** | Epps-Pulley 검정 | 정규성 검정을 위한 통계량 |
| **Cramér-Wold theorem** | 크라메르-볼트 정리 | 모든 1차원 사영이 같으면 결합분포도 같다는 정리 |
| **Violation of Expectation (VoE)** | 기대 위반 평가 | 물리 법칙 위반 상황에서 놀람(surprise)을 측정 |
| **Probing** | 프로빙 | 잠재 표현에 담긴 정보를 별도 예측기로 측정 |
| **Rollout** | 롤아웃 | 모델을 반복 적용해 미래 상태를 전개하는 과정 |
| **Task-agnostic** | 태스크 불가지론적 | 특정 과업에 종속되지 않는 |
| **Reward-free** | 보상 비의존 / 보상 없는 | 보상 신호 없이 학습하는 설정 |
| **Vector Quantization (VQ)** | 벡터 양자화 | 고차원 벡터를 압축하여 표현하는 기법 |
| **Quantization** | 양자화 | 연속적인 값을 이산적인 값으로 변환하는 과정 |
| **Bit-width** | 비트 폭 | 데이터를 표현하는 비트의 개수 |
| **Mean-Squared Error (MSE)** | 평균 제곱 오차 | 원래 값과 양자화된 값 사이의 오차 측정 지표 |
| **Inner Product** | 내적 | 두 벡터 사이의 곱셈 연산 성질 |
| **Distortion Rate** | 왜곡률 / 왜곡-율 | 정보 손실에 따른 변형 정도 |
| **Quantized Johnson-Lindenstrauss (QJL)** | 양자화된 존슨-린덴슈트라우스 변환 / QJL | 차원 축소와 양자화를 동시에 수행하는 기법 |
| **Online Quantization** | 온라인 양자화 (실시간 양자화) | 데이터 전체를 보지 않고 실시간으로 수행하는 양자화 |
| **Near-optimal** | 근최적 / 최적에 가까운 | 이론적 한계값에 근접한 수준의 성능 |
| **KV Cache** | KV 캐시 | 트랜스포머 모델에서 연산 가속을 위해 저장되는 키-밸류 값 |
| **Accelerator** | 가속기 (GPU, NPU 등) | 특정 연산을 빠르게 수행하도록 설계된 하드웨어 |
| **Data-oblivious** | 데이터 불가지론적 / 데이터 비의존적 | 데이터의 통계적 특성에 의존하지 않는 알고리즘 |
| **Beta distribution** | 베타 분포 | 고차원 구체에서의 좌표 분포 특성 |
| **Lloyd-Max quantizer** | 로이드-맥스 양자화기 | MSE를 최소화하도록 설계된 최적 스칼라 양자화기 |
| **Needle-In-A-Haystack** | 건더기 찾기 (니들 인 어 헤이스택) | 긴 문맥에서 특정 정보를 찾아내는 테스트 |
| **Product Quantization (PQ)** | 곱 양자화 / 프로덕트 양자화 | 벡터를 부분 벡터로 나누어 각각 양자화하는 기법 |
| **Indexing time** | 인덱싱 시간 | 데이터 검색을 위해 구조화하는 데 걸리는 시간 |
